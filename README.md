# resQ

A disaster response and emergency management platform consisting of a mobile app and a backend API.

## 📁 Repository Structure

```
resQ/
├── resq-backend-main/   # Spring Boot REST API (Java)
└── ResqApp-main/        # Android Mobile App (Kotlin)
```

## 🛠️ Tech Stack

### Backend (`resq-backend-main`)
- Java + Spring Boot
- Maven
- REST API

### Mobile App (`ResqApp-main`)
- Kotlin + Android
- Gradle

## 🚀 Getting Started

### Backend
```bash
cd resq-backend-main/resq-backend-main
./mvnw spring-boot:run
```

### Android App
Open `ResqApp-main/ResqApp-main` in Android Studio and run the project.
